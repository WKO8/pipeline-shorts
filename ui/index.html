🔑 Conexão de Plataformas & Guia TikTok API

📱 Passo a Passo para Obter o TikTok API (Sua Conta)

  1. Acesse o portal oficial: TikTok for Developers e faça login com a conta do seu TikTok.
  2. No menu superior, vá em "Manage apps" e clique no botão "Create an app".
  3. Dê um nome para seu app (ex: Pipeline Shorts Analyzer) e selecione a categoria.
  4. Na aba "Products", adicione:
    • Login Kit: Dá acesso ao fluxo de autenticação e leitura de dados.
  5. Na seção "Add Scopes" (Permissões de Acesso), marque:
    • user.info.profile: Acesso ao link público, bio e verificação da conta.
    • user.info.stats: Dados estatísticos de likes, contagem de seguidores e vídeos.
    • video.list: Leitura dos vídeos públicos postados no canal.
  6. Em "Redirect URI", adicione: http://localhost:7860/api/virality/tiktok/callback (e para seu domínio: https://app.exemplo.com/api/virality/tiktok/callback).
  7. Copie o Client Key e o Client Secret gerados e adicione no arquivo .env: 
    TIKTOK_CLIENT_KEY=seu_client_key
TIKTOK_CLIENT_SECRET=seu_client_secret
  8. Modo Ágil sem esperar aprovação: Você já pode usar a aba "Link" ou "Meus Vídeos Conectados" digitando apenas seu @username — o sistema puxa os vídeos automaticamente via extrator nativo!

▶️ YouTube Data & Analytics API

Adicione sua chave ou credenciais OAuth no arquivo .env: 

YOUTUBE_API_KEY=sua_api_key_do_google_cloud
